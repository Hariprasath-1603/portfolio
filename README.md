# HariOS 🚀

HariOS is a Windows 11-inspired personal portfolio showcasing the skills, projects, and AI/ML experiments of Hari Prasath.

## Features ✨
- **Windows 11 UI**: Experience a fully functional desktop environment built with React.
- **Terminal**: A mock terminal to run custom commands and navigate the portfolio.
- **AI Lab**: A dedicated space showcasing Agent Scholar, VisionCrafter, and other ML experiments.
- **Custom Apps**: Includes File Explorer, Edge Browser, VS Code, Calculator, and more.

## Tech Stack 🛠️
- **Frontend**: React, Tailwind CSS, Framer Motion
- **State Management**: React Hooks
- **Drag & Drop**: react-draggable

## Getting Started 🚀
To run this project locally, follow these steps:
```bash
# Clone the repository
git clone https://github.com/Hariprasath-1603/HariOS.git

# Navigate to the directory
cd HariOS

# Install dependencies
npm install

# Start the development server
npm start
```
